基于STM32的智能空气净化器
 
项目简介：
 
STM32+FreeRTOS多任务开发智能空气净化器，采集PM2.5、温湿度，自动调节风扇档位；本地LCD触摸LVGL人机交互，MQTT连接巴法云，支持云端查看数据、远程控制设备。
 
技术栈
 
C语言、STM32、FreeRTOS、LVGL、PWM、ADC、MQTT、DHT11
 
功能：
 
1. 传感器采集：ADC采集PM2.5，DHT11读取温湿度；ADC数据采用去极值取平均滤波
​
2. 执行机构：PWM控制风扇转速，驱动负离子发生器；自动模式根据PM2.5阈值自动调速
​
3. 按键：key0切换自动/手动；key1控制负离子；key3唤醒低功耗；按键使用计数法软件消抖；PM2.5＞500系统强制唤醒
​
4. 人机界面：320*240并行触摸LCD，LVGL绘制UI（LCD底层驱动由厂家提供）
​
5. 云通信：MQTT上传PM2.5、温湿度至巴法云平台，云端可远程控制风扇、负离子发生器
 
运行：
 
1. Keil MDK打开工程编译烧录至STM32
​
2. 上电后系统启动，LVGL界面直接操作，联网后自动上报数据至巴法云
 
代码说明：
 
LCD底层驱动使用厂商例程；FreeRTOS任务逻辑、传感器采集、滤波算法、按键处理、LVGL业务页面、MQTT业务逻辑为自主编写。
